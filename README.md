# Thale

A narrative created in Unity.

The player arrives at a strange, seemingly isolated house and encounters Thale, a blocky character, taken aback at a new face. Help Thale get his hands back! 

---

## Controls

| Action | Key |
|---|---|
| Move | WASD |
| Interact / Advance Dialogue | E |
| Cycle Artwork Forward | E |
| Cycle Artwork Backward | Q |
| Throw Away Artwork | T |
| Finish Artwork | F |

---

## Built With

- Unity
- Blender
- C#
- TextMeshPro

---

## Running the Project

1. Clone the repository
2. Open the project in Unity
3. Open the Main scene
4. Press Play

---

## Updating the Project
### Choice 1:
1. Use thaleUpdater script
```bash
cd path/to/Thale
python thaleUpdater.py
```
### Choice 2:
2. Use Git Commands
```bash
cd path/to/Thale
git pull
```
